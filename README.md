Repositório dedicado ao armazenamento, organização e versionamento de todos os exercícios, laboratórios e desafios práticos realizados durante a formação em **Python** na plataforma [freeCodeCamp](https://www.freecodecamp.org/).

O objetivo deste repositório é consolidar a base teórica e prática em lógica de programação, orientação a objetos e estruturas de dados, servindo como fundação para a criação de sistemas Back-End e automações.
