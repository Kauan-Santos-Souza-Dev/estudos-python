
# 🐍 Estudos em Python

> Repositório dedicado ao meu aprendizado contínuo, anotações de estudo e resolução de exercícios na linguagem **Python**.

Este repositório serve como um guia de consulta rápida e um registro do meu progresso no domínio da linguagem, cobrindo desde a sintaxe básica até conceitos avançados como Programação Orientada a Objetos (POO) e Tratamento de Exceções.

---

## 📚 Conteúdo do Repositório

O repositório está organizado por módulos, divididos nas seguintes categorias:

### 1. 🧱 Fundamentos Python (`/Fundamentos_Python`)
A base da linguagem. Contém anotações sobre:
*   **Introdução:** O que é Python e como funciona.
*   **Variáveis e Tipos de Dados:** Conceitos básicos, funções `type()` e `isinstance()`.
*   **Números e Operações:** Inteiros, floats e atribuições aumentadas.
*   **Strings:** Fatiamento (slicing), concatenação, interpolação e métodos comuns.
*   **Booleanos e Condicionais:** Valores *truthy*/*falsy*, operadores lógicos e *short-circuiting*.
*   **Funções:** Declaração, chamadas e escopo de variáveis.

### 2. 🔄 Loops e Sequências (`/Loops e sequências`)
Estruturas de repetição e armazenamento de dados em sequência:
*   **Listas e Tuplas:** Diferenças, criação e métodos comuns.
*   **Laços de Repetição:** Como funcionam os loops (for/while) e a função `range()`.
*   **Ferramentas úteis:** Funções `enumerate()` e `zip()`.
*   **Avançado:** *List Comprehensions* e *Lambda Functions*.

### 3. 📖 Dicionários e Conjuntos (`/Dicionários e Conjuntos`)
Estruturas de dados baseadas em chave-valor e elementos únicos:
*   **Dicionários (Dicts):** O que são, como funcionam e técnicas comuns para iteração.
*   **Conjuntos (Sets):** Operações de conjuntos e aplicabilidades.
*   **Módulos:** Introdução à Biblioteca Padrão do Python.
*   **Exercícios práticos:** Gerador de perfil de funcionário, Impressora de boletim, etc.

### 4. ⚠️ Tratamento de Erros (`/Tratamento_de_Erros`)
Lidando com exceções e depurando o código:
*   Mensagens de erro comuns no Python.
*   Estruturas `try`, `except`, `finally`.
*   Como levantar exceções com a declaração `raise`.
*   Técnicas de depuração (debugging).

### 5. 🏗️ Classes e Objetos (`/classes_objetos`)
Introdução aos moldes e instâncias no Python:
*   O que são classes, atributos e métodos.
*   Diferença entre classes e objetos.
*   Métodos especiais (Magic Methods / Dunder Methods).
*   Atribuição dinâmica de propriedades.

### 6. 🧩 Orientação a Objetos (`/orientacao_objetos`)
Aprofundamento no paradigma POO:
*   **Encapsulamento:** Proteção de dados e estruturação de código.
*   Uso de **Getters e Setters** para manipulação segura de atributos.

## 🚀 Como utilizar este repositório

Se você deseja clonar e executar os exemplos ou exercícios em sua máquina, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/SEU-USUARIO/estudos-python.git
   ```
2. **Acesse a pasta:**
   ```bash
   cd estudos-python
   ```
3. **Explore os arquivos Markdown (`.md`)** para ler as anotações teóricas.
4. **Execute os scripts (`.py`)** utilizando o Python 3:
   ```bash
   python nome_do_arquivo.py
   ```
